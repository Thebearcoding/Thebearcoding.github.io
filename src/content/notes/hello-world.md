做完两门互动课程之后,我发现自己一直缺一个「放东西的地方」——课程散在各自的仓库里,想法散在笔记软件里,而真正值得留下的思考,往往在这两者之间。

所以有了这个站。它做三件事:

1. **记录想法**:研究中的碎片、实验里的意外、读文献时的"等一下,这不对"。写在 `src/content/notes/` 下的一个 Markdown 文件里,推送即发布。
2. **收纳课程**:我做的互动课程都从[教学与学习](/teaching/)页进入。做课程是我学东西的方式——能讲清楚,才算真的懂。
3. **保持诚实**:笔记不追求完整。错了就改,想法变了就注明,比修饰过的"成果"更有价值。

## 写作约定

数学公式直接写 LaTeX,比如注意力的核心一行:

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

代码块带高亮:

```python
def attention(q, k, v):
    scores = q @ k.T / math.sqrt(q.shape[-1])
    return softmax(scores) @ v
```

> 站点用 Astro 搭建,设计延续了课程的暖色体系——衬线正文、米色底、一点橙。反对千篇一律的深色科技风。

就这样,开张了。
